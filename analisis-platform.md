# Analisis Perbedaan Platform

## 1. Perbandingan Platform Aplikasi

| Aspek | Mobile | Desktop | Web |
|---|---|---|---|
| Perangkat | Smartphone | Komputer atau laptop | Berbagai perangkat |
| Cara penggunaan | Melalui aplikasi HP | Melalui aplikasi yang diinstal | Melalui browser |
| Kelebihan | Praktis dan mudah dibawa | Fitur lebih lengkap dan nyaman digunakan | Bisa diakses tanpa instalasi aplikasi |
| Kekurangan | Ukuran layar terbatas | Bergantung pada perangkat komputer | Membutuhkan browser dan koneksi internet untuk layanan online |
| Contoh | WhatsApp Mobile | Microsoft Word | Google Docs |

## 2. Kesimpulan

Setiap platform memiliki kelebihan dan kekurangan
masing-masing. Platform mobile lebih praktis untuk
penggunaan sehari-hari, desktop cocok untuk pekerjaan
yang membutuhkan fitur lebih lengkap, sedangkan web
memudahkan pengguna mengakses aplikasi melalui browser.
